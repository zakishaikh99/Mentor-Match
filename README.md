# Mentor Match

Mentor Match is a simple platform that connects mentors and mentees based on their interests, skills, and goals.

## Features

* User registration and login
* Mentor and mentee profiles
* Mentor matching
* Search and discover mentors
* Connect with matched mentors

## Tech Stack

* Frontend: Html
* Backend: Python
* Database: MongoDB

## Installation

```bash
git clone https://github.com/zakishaikh99/Mentor-Match.git
cd mentor-match
npm install
npm run dev
```

## Usage

1. Create an account.
2. Set up your profile.
3. Find a suitable mentor.
4. Connect and start learning.
